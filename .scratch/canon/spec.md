# 规格：原著同人（`canon`）

> 来源：2026-11-20 人类要求「导入长篇小说原文，按原著玩同人角色卡」，参考人类本机的「原著指导」卡（未入库，只参考其行为与结构）。方案见 `docs/proposals/v5.md` 第五节。

## 要点

- 导入 txt（编码自动识别）→ 分章（可预览、合并、拆分）→ 预估 token → 按章后台抽取（事件、话术、实体增量；可暂停续跑）→ 全书汇编（合并别名、排时间线、生成记事页底色与一行简介）→ 原著故事包。
- 游玩：每轮上下文给原著窗口「当前」一件，推进时再给「接下来」1–3 件；话术 / 原文按设置叠加；偏离规则写进固定说明；死人与不在场处理；原著游标随楼层存，由局面更新顺带判断是否演完。
- 原著事件可就地编辑并按格版本化；「从这里开始」；推进到下一件 / 推进 N 件与玩家本轮输入一起生效。

## 约束

- 原文与抽取结果只在玩家本机 `data/`；测试只用合成小说 fixture（I10、私有数据规则）。
- core 里叫「原著」，不出现任何 ST 概念（I1）。
- 抽取是后台任务，回合内不调用（I11）；导入前必须显示预估并由玩家确认。
