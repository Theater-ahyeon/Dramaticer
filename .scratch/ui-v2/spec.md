# 规格：界面重构（`ui-v2`）

> 来源：2026-11-20 人类确认 `docs/proposals/v5.md` 第五节。走查截图在 `.devloop/scratch/walk/`（不入库）。交互参照人类的 TauriTavern 设置（路径见 AGENTS.md 安全红线里的只读目录；只读 settings，不读 secrets）。

## 问题

主导航与「更多」旧面板两张皮；渠道绑在故事下；导卡要过浏览器原生 prompt 和旧面板；开场白与开局候选不显示；输入台主次按钮颠倒、信息过载，手机上占近半屏；助手只在旧面板；遥测铺在一级界面；文案有说明书腔与文艺腔。

## 原则

- 读与写是一个动作：故事页默认只有正文与一行输入台。
- 全局的东西（模型渠道、外观、助手、检视器）不挂在故事下。
- 研发信息只在检视器里。
- 文案只用人话和标准软件术语（v5 §5.4）。

## 不做

- 不改协议里已有接口的语义；需要的新接口随工单登记。
- 不追求经典酒馆界面一致（I15）。
