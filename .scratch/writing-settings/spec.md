# 规格：写作与卡的配置

> 设计出处：v4 第十四节 14.5、14.6。命名按 `GLOSSARY.md`。

## Problem Statement

玩家要在上百条预设条目里勾选才能定下文风和人称；卡更新后会影响正在玩的长故事。

## Solution

少量明确的写作选项，导入预设时自动对应；卡可以带推荐配置；故事固定自己用的那一版卡。

## User Stories

1. 作为玩家，我用几个选项定下文风、人称、长度、节奏、尺度、思考、是否替我行动
2. 作为玩家，我导入预设后大部分条目自动对应到这些选项
3. 作为玩家，对应不上的预设条目可以整体开关
4. 作为卡作者，我的卡可以带推荐的写作选项、写法与功能开关
5. 作为玩家，我的调整叠在卡的推荐之上，可以一键回到推荐
6. 作为玩家，卡库里的卡更新后，我进行中的故事不变，除非我选择升级

## Implementation Decisions

- 写作选项是故事设置的一部分，进入上下文模板的条件段
- 预设导入时按条目名与内容把条目映射到选项，其余归为文风包
- 推荐配置写在卡的 dramaticer 扩展字段里
- 故事创建时保存所用卡与设定的版本

## Testing Decisions

- 只测对外行为，不测实现细节。
- 在导入与故事设置接口处测：映射结果、叠加与恢复、快照隔离。用合成预设 fixture。
- 单元测试不访问网络、不使用私有数据（I10）。

## Out of Scope

面板编辑、开玩向导、导入时的外部资源预检（见 PARKED）。
