# 规格：三速记忆（`memory-v5`）

> 来源：2026-11-20 人类确认 `docs/proposals/v5.md` 第三节（采纳 Gemini 的三速分层）。

## 目标

| 层 | 内容 | 更新 |
|---|---|---|
| 此刻局面 | 时间、地点、在场者、关键物品与伤势、当前冲突；秘密 → 谁知道 / 谁不知道 | 每楼 1 次轻量增量（与行动选项合并成一次后台调用） |
| 故事记事 | 每个实体一页：底色（只追加）、现在（2–3 句，场末刷新）、经历（带楼层锚点，只追加） | 每场末 1 次补丁式编译 |
| 归档 | 原文、场与章摘要、带实体标签的记录、向量 | 场末入库 |

常驻世界索引：每个实体与未收的线一行，约 200 字，由程序从记事页的一行简介拼出。

## 原则

- 复用现有底座：只追加的记录表（`memory_events`）作为归档层，状态与秘密投影作为局面层的数据来源，检索与重逢注入保留。新增的是：记事页存储（分节、按场的版本）、场末编译、局面卡渲染、世界索引。
- 出处用楼层锚点 `[F128]`；校验只拦两件事：与玩家锁定的事实冲突、让未知情者知道秘密。格式问题由程序修复，不打回。
- 玩家直接编辑：改过的节锁定，后台编译跳过；每次修改有版本，可撤销。不再有变更卡审批。
- 记事页的旧版本只追加（I4 的精神延伸到玩家可见的记忆），回滚是新建版本。

## 不做

- 不让后台每楼重写整页（X1 已证伪，ADR-0130）。
- 不依赖外部记忆服务。
