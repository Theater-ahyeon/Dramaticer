# 规格：轻量、美观的前端（`ui-lite`）

> 来源：2026-11-19 人工会话，人类要求「根据完整功能与最优设计，做出轻量化、最美观的前端界面」。功能与页面结构沿用 `docs/DESIGN.md` §22 与 `ui/*` 工单的成果；本规格只改**体积、视觉与阅读体验**，不改接口与数据。

## 现状（2026-11-19 构建产物）

| 部分 | 体积 |
|---|---|
| 主 JS | 598 KB |
| CSS | 342 KB（`styles.css` 3,192 行 + `v4.css` 3,611 行 + 187 个字体分片的 @font-face） |
| three.js 背景分包 | 558 KB |
| 打包字体 | 187 个 woff2，约 14 MB |

另外：玻璃拟态（`backdrop-filter`）、指针光、卡片倾斜、每次打开都播放的 3 秒开场，在手机上耗电、掉帧，也和「长时间阅读」的主场景冲突。

## 设计方向

- **读书，不是看特效**：正文是主角。亮色是温暖的纸，暗色是墨；正文用衬线、界面用无衬线，都用系统字体（思源宋体 / 宋体 / 苹方 / 微软雅黑等本机字体），不打包字体。
- **一个强调色**：朱砂红只用在主操作、当前位置与导演的痕迹上；其余靠灰阶与留白区分层级。
- **安静的表面**：不用玻璃模糊与大面积渐变；层级靠细边线、轻阴影和背景明度差。
- **自动暗色**：跟随系统，可以在设置里手动固定。
- **动效克制**：只保留页面转场（View Transitions）与状态反馈；系统设了「减少动效」时全部关闭。
- **手机优先**：触控目标 ≥ 44px，底部输入台不被键盘挡住，停靠栏变成底部抽屉。

## 预算（写进检查脚本）

首屏 JS（gzip）≤ 200 KB；CSS（gzip）≤ 40 KB；不出现字体文件；不加新的运行时依赖。

## 约束

- 不改接口、协议类型与数据；不改页面路由。
- 尽量保留现有类名与可访问名称，端到端用例（Playwright）不为换皮重写；必须改的选择器在同一张工单里同步。
- 每张工单结束跑 `pnpm check` 与 `pnpm e2e`。
