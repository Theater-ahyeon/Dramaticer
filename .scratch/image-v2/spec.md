# 规格：剧情插图（`image-v2`）

> 来源：2026-11-20 人类要求 NovelAI 参考「智绘姬」（st-chatu8）。上游与修改版均为 Aladdin Free Public License，**只按公开文档描述的行为独立实现，不复制、不移植源码**（同 HUMAN-17、18 的做法）。基础后端已在 ADR-0167 完成。

## 借鉴的行为

- 楼层落定后，由一次后台调用（「画面整理」）读本楼正文、最近几次出图的提示词与视觉定义，输出结构化结果：场景构图、每个出场人物的提示词、物件与场景定义。
- **视觉定义**按人物 / 场景 / 物件分别保存、有稳定编号，后续出图回注入；「常驻」人物始终带最新定义。现有的角色视觉档案扩展成这三类。
- 引用最近 N 次出图的提示词，保持画风与构图连续。
- 出图失败时复用已整理好的提示词重试，不重跑整理。
- 生成期间切换分支或改了正文，结果不写回旧楼层（现有：只处理当前路径）。

## NovelAI 多人物

V4 及以上用多人物提示词：每个出场人物一条 caption（可带位置），人物级负面提示；基础提示写场景与构图。字段格式以 NovelAI 网页端实际请求为准，实现前先做一次实测或找到可核对的公开文档，不凭记忆写。

## 不做

- 不建跨故事的全局人物库。
- 不在回合内出图（I11）。
