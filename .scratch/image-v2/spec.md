# 规格：剧情插图（`image-v2`）

> 来源：2026-11-20 人类要求 NovelAI 参考「智绘姬」。已读人类本机智绘姬 3.1.9 的设置与源码（只读）；其许可证为 Aladdin Free Public License，**只按行为独立实现，不复制代码与提示词**。智绘姬只是参考之一，默认值与流程同时参考其他生图插件和通用做法，不以一位玩家的配置为准（ADR-0170）。方案见 `docs/proposals/v5.md` 第六节；基础后端已在 ADR-0167 完成。

## 要点

- 后台岗位「画面整理」：输入本楼（或本场）正文、在场者记事页、世界索引、按关键词触发的标签库条目、最近 N 次出图提示词；输出若干张图，每张：插入段落、标题、画面描述、构图提示、每个人物的提示（只写谁、视角、可见部位、穿哪套）、人物级负面、可选坐标。
- 程序展开：人物外貌按「脸 / 上身 / 全身 × 正 / 背 × 着装 / 裸露」分格，服装独立并归属人物；去重、全角标点清洗、替换规则。
- NovelAI 请求体按模型族生成：V3、V4.x（多人物 caption + 坐标 + 人物级负面 + characterPrompts）、V5（params_version 4、不发 skip_cfg 与旧参考数组、噪点表默认不发、tag_hint_*、straight_alpha、Medium 档换模型）；负面预设 Heavy / Light / Human Focus / Furry Focus / None。
- 默认每场末 1 张或手动「画这一幕」，可设为每楼；本地队列、429 退避、每分钟上限。
