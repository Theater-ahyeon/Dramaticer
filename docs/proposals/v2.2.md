# Dramaticer v2.2 补充提案（2026-11-07，已获人类确认）

> v2（ADR-0033）和 v2.1（ADR-0035）的补充。参考来源：TauriTavern 的 Agent 框架和应用内助手（源码与文档在 `E:\codex\tauritavern-upstream`，AGPL-3.0，**只借鉴设计，不复制代码**）、WeKnora 的权限分级。

## 一、深回合的设计要点（R3-T00 细化时纳入）

| 编号 | 内容 |
|---|---|
| D1 | **草稿和提交分开**：深回合里，模型先把正文写成草稿，可以自己反复修改，满意之后才提交为楼层。草稿实时投影到界面上，玩家能看到写作过程。没有提交就结束的运行不产生楼层 |
| D2 | **导演手记**：深回合给模型一本跨回合的笔记，它可以自己记下伏笔安排、人物动机、后续打算，下次深回合可以读写。**手记挂在楼层树上**（每楼存修改，沿路径累加），每个分支有自己的版本。手记是模型自己的工作材料，不是事实来源；事实仍然以台账为准（I12） |
| D3 | **运行日志**：深回合的每一步（模型调用、工具调用、草稿修改、提交）都只追加地记录下来，并入现有的 Trace，界面上用时间线展示。进程崩溃后能看到停在哪一步 |
| D4 | **模板里的深回合配置**：原生上下文模板可以附带深回合的配置（开放哪些工具和技能、计划方式、防失控上限）。卡作者可以为自己的卡定制深回合 |
| D5 | **原生元数据保真**：深回合的多轮工具调用必须原样回放各家模型的原生元数据（尤其是 Gemini 的思考签名），否则工具循环会出错。写专门的测试，并且用中转渠道实测 |
| D6 | **技能格式**：v2.1 暂缓的"卡片技能"，以后采用 `SKILL.md` 目录格式（和 Claude、omp、TauriTavern 互通） |

## 二、应用内助手（取代 v2 第八节的"侧边 agent"）

### 定位
一个助手，多个技能。和正剧隔离：不写楼层，不进入剧情上下文。复用深回合的 agent 运行时，只是工具集和权限不同。

### 技能
- **排障**：读 Trace、上下文组装记录、检索分数、预算裁剪记录、台账和导演决策，解释"这一轮为什么这么写、为什么忘了某件事"，并给出可以操作的修正（例如置顶某条记忆、修订台账）。**这是 Dramaticer 独有的价值，优先做。**
- **台账修订**：v2.1 的 A3，用自然语言生成变更卡
- **参谋**：商量剧情走向，产出弧线、序列或剧情小品
- **资料员**：为同人卡调研原作，产出原作资料包草稿
- **卡片工坊**：读写角色卡、世界书和模板
- **设置向导**：渠道、预设、模型、深回合配置
- **使用指南**：内置只读的知识技能（使用说明、设计文档、排障手册），直接回答"怎么用"

### 操作方式
- **通过类型化的 server 接口操作**（读 Trace、改设置、生成变更卡……），不靠模拟点击；截图只作为可选补充，不要求模型支持图片输入。
- **权限分三级**：只读 / 修改前确认 / 自动执行，由玩家设置。**凡是影响剧情的修改（台账、记忆、设定、模板），一律走变更卡，需要玩家确认。**

### 体验
在输入框里选择模型和思考强度；对话自动保存，可以搜索、重命名、删除；关掉抽屉后任务继续运行，有运行状态提示；上下文快满时自动压缩，也可以手动压缩；显示上下文用量环。

### 路线
- **排障技能先做命令行版本**（`dramaticer explain --node <id>`），排在 R2 之后。开发 agent 分析"为什么这一轮输了"时就能用上。
- 完整的助手（抽屉界面加全部技能）排在 R5 之后，**取代 R7 里原来的"侧边 agent"条目**。
