> 2026-11-20。起因：人类要求「针对整个项目的机制给一个最好的方案」，并附上三份外部评审（界面操作逻辑、五个设计矛盾、Gemini 的三速记忆）。本文先从 AIRP 的第一性原理推出取舍标准，再逐条判定评审意见，最后给出目标形态与工单。**待人类确认后再拆工单执行**；其中改动不变量的条目单列在第七节。

> 依据：本仓库代码与 DESIGN；2026-11-20 用 Playwright 在假渠道下实际走查全部页面的截图（`.devloop/scratch/walk/`，不入库）。

## 一、AIRP 是什么，玩家要什么

AIRP 的本质：**玩家与一个模型合写一个自己身处其中的长故事**。玩家既是读者，也是一个角色。拆开看，玩家要的只有五件事，重要性递减：

1. **下一段好看**：文笔、语气、情绪的连续。这是模型的事，系统能做的只是「别妨碍」——不往上下文里塞干扰物。
2. **我的选择算数**：写了行动，故事按我的走；没写时，故事自己能往前动。
3. **它记得**：人物不忘事、不知道不该知道的事、旧伏笔有人收。
4. **不打断**：从读到写是一个动作；任何要玩家「管理系统」的时刻都是摩擦。
5. **花得起**：玩家自付 token，后台每多一次调用都是玩家的钱和限流额度。

再看 2026 年模型的能力边界：

| 模型擅长 | 模型不擅长 |
|---|---|
| 文笔、语气、在给定局面下写下一段 | 发现自己忘了什么（不知道要去查） |
| 读几万字原文、长上下文 | 几百楼尺度上的一致性 |
| 按清楚的少量约束行事 | 同时满足十几块格式各异的指令 |
| 场景级的理解与总结 | 单楼碎片里稳定抽出严格结构 |

由此得到系统的唯一职责：**补模型的短板，且不制造新的摩擦与开销**。具体只有三件：

- **记得**：把「模型不知道自己忘了的东西」以低噪声的方式递到它面前；
- **守界**：秘密的知情边界、玩家锁定的事实，这是模型最容易破、玩家最在意的；
- **给方向**：玩家想让故事自己走时，提供可选的方向，而不是替玩家决定。

其余一切（多种写法、导演动作分类、变更卡、遥测）都要回答同一个问题：**它让每百楼带原因的重写次数下降了吗，代价是多少？** 答不上来的，进实验区或删除。

| Gemini：三速分层记忆（局面 / 场末编译百科 / 冷归档） | **采纳为记忆层目标** | 与第一节的推导一致；X1 失败的是「每楼重写整页」，场末**补丁式**编译避开了它。全局索引直接解决 §3 第 8 条「模型不会搜它不知道自己忘了的东西」。 |

我**不同意**的一点：评审建议「后台整理完直接更新、去掉校验」。校验要保留，但只做两件程序擅长的事——**不与玩家锁定的事实冲突、不让未知情者知道秘密**；其余格式问题由程序修复，不打回、不弹给玩家。

## 三、目标形态：记忆与上下文

### 3.1 三速记忆

| 层 | 内容 | 更新 | 体积 |
|---|---|---|---|
| **此刻局面** | 时间、地点、在场者；关键物品与伤势；当前冲突；**秘密 → 谁知道 / 谁不知道** | 每楼一次轻量增量（与选项生成合并为一次后台调用） | ≤ 500 token，自然语言卡片 |
| **故事记事**（百科） | 每个实体一页：「底色」（卡与不可逆转折，只追加）、「现在」（2–3 句，场末刷新）、「经历」（带楼层锚点的压缩事件，只追加） | **每场结束**一次补丁式编译，不全文重写 | 按需注入 |
| **归档** | 不可变原文、场次与章摘要、带实体标签的事件索引、向量 | 场末入库 | 不常驻 |

外加常驻的 **世界索引**：每个人物、地点、关键物品、未收的线各一行（约 200 字），让模型知道「世界里还有什么」，需要细节时由程序按在场/重逢注入整页，或模型调用读取工具。

### 3.2 上下文从 15 槽位收拢为 6 节

1. 卡与写作条目（作者内容与玩家的写作设置，含预设注入，ADR-0167）
2. 世界索引（~200 字）
3. 此刻局面与知情边界（~500 字）
4. 相关页面：在场者与重逢者的记事页；检索命中时带上所在场的摘要或前后一楼原文（父文档回溯），不塞孤立句子
5. 剧情走向提示：**只在玩家按推进时**出现，一两句
6. 最近原文窗口：放得下就全放，不检索；放不下时远粗近细（最近 10–15 楼原文、更早场摘要、再早章摘要）

### 3.3 后台调用预算

| 时机 | 调用 | 现在 |
|---|---|---|
| 每楼 | 1 次：局面增量 + 行动选项 | 场记、结算补写、事件抽取、嵌入、选项、复查等多次 |
| 每场末 | 1 次：场摘要 + 记事补丁 + 剧情走向更新 + 入库 | 归档、档案更新分散 |
| 每章末 | 1 次（可选更强模型）：清点未收的线 | 不变 |
| 推进预跑 | 只预跑「推进·一步」一条 | 推进三档 + 每个选项最多 8 条 |

指标：每楼平均后台调用数、每楼后台 token，与北极星重写率并列显示在检视器里。

## 四、目标形态：导演改为「剧情走向」

- **一页剧情走向**，合并大纲、剧情线、伏笔、本场目标、里程碑：只有两栏——「想发生的」（玩家与卡写的方向，可锁定）与「还没收的线」（后台场末更新，越老越靠前）。
- **推进**时，后台已备好 2–3 个方向（取自走向页），以菜单形式给玩家点选；玩家直接写了行动就什么都不加（保留「不干扰玩家」）。
- **删除每拍的程序动作选择器**（八种动作）。理由：它是叠在根因之上的启发式，没有证据显示有用（`mechanisms`、`bits` 已先后落选），且与 I13 有张力。保留章末清点。
- 开局：卡的开场白立即显示为第 0 楼；开局候选作为可替换的开场卡片显示在故事页。

## 五、目标形态：界面

### 5.1 信息架构（消灭双壳）

| 位置 | 内容 |
|---|---|
| **书架**（全局） | 故事卡片；「新建故事」弹窗（导入角色卡 / 空白开局，导完直接进故事页）；右上角「模型与渠道」 |
| **故事页** | 正文与输入台。顶部：标题、分支下拉；「⋯」菜单：导出连载、本故事设置、检视器 |
| **记事** | 三张活页：此刻局面、故事记事（百科）、剧情走向。像笔记一样就地修改，改过的自动锁定，旁边可撤销 |
| **设定** | 卡、世界书副本、写作条目、导入体检（子页） |
| **设置**（全局） | 模型与渠道（向导式：选供应商 → 填 key → 一键测试）、外观、默认写作选项 |
| **检视器**（抽屉，全局快捷键） | 本轮上下文与来源、token 与耗时、后台任务、拒收记录、渠道体检、重写率 |
| **助手**（抽屉，全局快捷键） | 任何页面都能呼出 |

「更多」与其下 10 个旧面板全部拆除：导入 → 新建弹窗；体检 → 设定子页；分支 → 故事页顶部；台账 → 记事「此刻局面」；连载 → ⋯ 菜单；导演 → 剧情走向；生图 → 设置；设置 / 渠道 → 全局设置；旧聊天页删除。

### 5.2 故事页

- 输入台默认只有：行动选项（点一下直接发送，旁边铅笔图标才是填入修改）、输入框、主按钮。**输入框有字时主按钮是「发送」；为空时是「推进」**，推进的一步 / 一场 / 跳跃收进按钮旁的下拉。写法切换、批注开关收进输入台左下角一个「⋯」。
- 每楼悬停（手机长按）：重写（可选原因）、改这句、从这里分支、看上下文（打开检视器）。
- 撤回导演安排：「仅撤回」与「撤回并重写这一楼」两个按钮。
- 批注默认关；开着时只说人话（「林雪起了戒心」），不显示内部路径。
- 状态栏与卡片界面走渲染插件（5.3），不以等宽键值对显示。
- 手机端：输入台默认一行，聚焦时展开；正文区至少占屏幕 70%。

### 5.3 卡片前端：渲染插件，而不是解析出字符

现状：沙箱渲染器 `SandboxBlock` 与酒馆助手沙箱 `buildStHelperSandboxDocument` 都已实现，但**都没有接进现在的故事页**（前者只在旧聊天页，后者只在测试里）。目标：

- 原生扩展点「楼层渲染器」（插件内核已有的显示视图，I8：从原文派生，不改原文）：插件声明它认领的块或正则，返回沙箱 iframe 内容。
- `st-content` 的美化正则与 `st-helper-host` 作为第一个渲染插件：卡的状态栏、按钮、选项面板在 `sandbox="allow-scripts"` 的 iframe 里原样运行。
- 交互桥：iframe 内的点击通过 postMessage 只能调用白名单动作——发送一条消息、填入输入框、读取变量、经结算器写入变量（I16、I18，未声明的调用拒绝并记录）。

### 5.4 文案规则

界面只用人话和标准软件术语：不写解释架构原则的句子，不用文艺腔，不用「它」指代模型，占位符只说操作。首批替换（全部见工单）：

| 现在 | 改为 |
|---|---|
| 这里没有路 / 灯塔照不到这一页 | 页面不存在 |
| 它看到了什么 | 上下文 |
| 写下你的行动或台词。只要你写了，导演就不插手 | 输入行动或对话（Enter 发送，Shift+Enter 换行） |
| 哪里不满意？ | 重写原因（可选） |
| 这不是我要的 | 撤回 |
| 不想 / 想一下 / 多想 | 关闭 / 低 / 高 |
| 省 / 均衡 / 全开 | 轻量 / 标准 / 完整 |
| 还能走到 / 走不通了 / 已发生 | 进行中 / 已偏离 / 已达成 |
| 没认出 | 未分类 |
| 还没有写下第一楼 | 暂无内容 |
| 条剧情线在走 / 个伏笔没收 | 剧情线 N · 未收的线 N |
| 记忆与导演暂停了……正文照常能写…… | 后台任务连续失败 N 次：原因。〔检查渠道〕 |
| 每一项都能随时开、随时关。晚开的功能会在后台把前面的楼层补上。 | （删除） |
