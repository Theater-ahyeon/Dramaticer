## 五、限制

- R2 报告从已保存的评测记录重新计算，没有重新生成正文或裁判判定。重新生成会引入随机波动，不能作为“数字不退化”的判据；保留行为由 1611 个测试与上述聚合数字一致共同证明。
- P2 没有修改数据库 schema、渠道配置或评测口径；旧评测记录与当前代码使用同一套解析函数。
