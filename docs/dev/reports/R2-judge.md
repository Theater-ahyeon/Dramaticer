# R2 裁判校准（R2-T03.b）

## 预先登记的判定规则（运行前写入）

### 第一部分：F0 配对上的协议校准

- 沿用 F0-T03 的协议：同一批回复对隐去标签，以「被放弃的在位置甲」与「被保留的在位置甲」两种顺序各判一次。
- 门槛沿用 F0-T03 的预注册值：交换顺序后裁判与玩家实际选择的一致率 ≥ 65%，位置偏差 ≤ 10 个百分点。
- 两项都达到时，`judge` 可以用于扩展偏好判断的聚合样本；单次判断不作为偏好结论。
- 未达到时，`judge` 不用于重 roll 与偏好判定；R2-T04 的盲测改用确定性指标加配对统计，并在报告里注明。

### 第二部分：自动试玩回复上的判定尺度

- 取一轮自动试玩的 100 条助手回复，把同一个玩家侧问题（会不会重 roll、是否遵循指令）分别交给 `judge` 与模拟用户模型。
- 参考信号：模拟用户模型对同一回复的判定。自动试玩还没有记录玩家的行为偏好（R2-T07 待做），这份参考说明两个评审的尺度是否一致，不代表玩家的真实 swipe。
- 判定尺度偏宽松的界：可判定样本不少于 50 条，且 `judge` 的重 roll 率比参考低 5 个百分点以上。
- 判为偏宽松时，`judge` 不用于重 roll 判定；样本不足时只报告数字，不判定尺度。
