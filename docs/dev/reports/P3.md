## 四、限制

- P3 完成的是格式、解析、叠加、按故事解析与导入报告。声明式插件还没有接进运行时装载器：台账 schema、块渲染器、技能与玩法包配置尚未注册到内核，实际应用留给后续任务。验收按数据层与解析层核对。
- `dramaticer chat --card` 打印的每行文本直接取自 `CardDependencyIssue.message`；该字段在 core 测试里逐字断言，CLI 没有单独断言输出行。
- 本次验收没有调用真实模型或私有数据，全部为合成测试数据。
