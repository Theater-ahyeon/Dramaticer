## 四、限制

- 代码插件目前只有库 API：清单、安装确认、worker 运行时、安装/更新/卸载与开发文档。`dramaticer` 命令行与 server 尚未接入，因此没有跨进程的实际安装与启动流程可做端到端验证。
- `dramaticer explain` 还没有读取 `CodePluginTraceEntry`；I17 的 Trace 证据来自运行时对象。
- 本次验收没有调用真实模型、npm 公网 registry 或私有数据，安装测试全部使用本地 fixture。
- worker 线程是故障隔离与能力中介，不是对抗性沙箱；信任依据是安装时展示并被确认的权限（ADR-0092）。
