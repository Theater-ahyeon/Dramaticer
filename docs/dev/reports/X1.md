- 逐故事看矛盾率：`wiki` 在 `xianxia` 与 `yinqi` 高于对照、在 `yuwang` 低于对照；`temporal_graph` 在 `xianxia` 与 `yinqi` 高于对照、在 `yuwang` 低于对照。两个候选都没有在三个故事上都不劣于对照。
- 裁判在位置互换下的判定一致性（`preferenceConsistency`）逐故事为：`wiki` 12.5%、37.5%、41.7%；`temporal_graph` 33.3%、13.0%、43.5%。两次判定不一致的记录为 `wiki` 23/48、`temporal_graph` 30/48。盲测结果作为辅助证据。
- 每轮请求在 1.00–1.04 之间，首字与时延没有一致方向（`xianxia` 的 `wiki` 首字 4,482 毫秒对对照 5,679 毫秒；`yinqi` 的 `temporal_graph` 首字 5,392 毫秒对对照 4,292 毫秒）。成本不是判定项。
